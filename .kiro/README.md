# 📚 Classio App - Documentación del Proyecto

## 🎯 Visión General

Classio es una app móvil offline-first para estudiantes universitarios que permite organizar horarios, gestionar evaluaciones y calcular notas académicas.

**Sin login, sin backend - 100% local y privado.**

## 🎨 Features Destacadas

- 🚨 **Semana Crítica**: Detecta semanas con alta carga académica
- 🧠 **Prioridad Inteligente**: Sugiere prioridades automáticamente
- 📊 **Calculadora de Notas**: Calcula promedios y nota mínima necesaria
- 🧩 **Checklist de Proyectos**: Divide proyectos en subtareas
- 📈 **Estadísticas**: Visualiza tu carga académica
- 📱 **Widget**: Acceso rápido desde la pantalla de inicio

---

## 📱 Pantallas del MVP

1. **Home** - Vista rápida del día
2. **Calendario de Clases** - Horario semanal
3. **Calendario de Evaluaciones** - Exámenes, tareas y proyectos
4. **Gestión de Cursos** - CRUD de cursos y notas
